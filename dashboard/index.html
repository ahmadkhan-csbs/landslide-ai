Data & Method

Loading current data status…
Current rainfall

IMD is the primary integration when configured. Open‑Meteo is a clearly labelled live fallback. Observed 1h, 24h and completed 7-day windows are stored separately from forecast rainfall.

Historical climate simulation

NASA POWER Daily rainfall data supplies historical/backfill data. Simulation uses the nearest source-station monthly climate value; it is not a live forecast.

Terrain and screening

Nearest available terrain-grid elevation/slope plus rainfall drive a prototype model score and a separate current rainfall-and-terrain screen. Neither is an official warning or calibrated real-world landslide probability.
